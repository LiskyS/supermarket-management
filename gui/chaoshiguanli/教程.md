## 🚀 第一章：使用PyCharm打开项目

### 1.1 准备工作

确保你已经安装了：
- **PyCharm**（推荐专业版，社区版也可以）
- **Python 3.8 或更高版本**

### 1.2 打开项目步骤

**步骤1：启动PyCharm**
- 双击PyCharm图标启动软件
- 如果是首次启动，选择"Open"按钮

**步骤2：打开项目**
1. 点击"Open"按钮
2. 在文件选择对话框中，找到 `f:\chaoshiguanli` 目录
3. 选择该目录，点击"OK"

**步骤3：等待项目加载**
- PyCharm会自动扫描项目文件
- 等待右下角进度条完成

### 1.3 创建虚拟环境

**方法一：使用PyCharm自动创建**

1. 打开项目后，按 `Ctrl+Alt+S` 打开设置
2. 找到 "Project: chaoshiguanli" -> "Python Interpreter"
3. 点击齿轮图标，选择 "Add Interpreter" -> "New environment"
4. 选择 "Virtualenv" 作为环境类型
5. 设置虚拟环境目录为项目下的 `venv` 文件夹
6. 选择Python解释器版本（确保是3.8+）
7. 点击"OK"

**方法二：手动创建**

1. 打开PyCharm的Terminal（底部工具栏）
2. 在Terminal中输入以下命令：
```bash
cd f:\chaoshiguanli
python -m venv venv
```

3. 激活虚拟环境：
```bash
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# Windows 命令提示符
venv\Scripts\activate
```

4. 配置PyCharm使用该虚拟环境：
- 打开"File" -> "Settings" -> "Project: chaoshiguanli" -> "Python Interpreter"
- 点击齿轮图标，选择"Add" -> "Existing environment"
- 找到 `f:\chaoshiguanli\venv\Scripts\python.exe`，点击"OK"

### 1.4 安装依赖包

本项目依赖包已写在 `requirements.txt` 文件中，只需在终端中执行一条命令即可全部安装。

**在PyCharm终端中安装：**

1. 确保虚拟环境已激活（终端前面显示 `(venv)`）
2. 在Terminal中输入：
```bash
pip install -r requirements.txt
```

3. 等待安装完成，会看到各个包的安装进度

**本项目依赖的包：**
| 包名 | 版本 | 用途 |
|-----|------|------|
| Flask | 2.3.2 | Web框架，搭建网站后端 |
| matplotlib | 3.7.1 | 生成数据分析图表 |

### 1.5 运行项目

**方法一：使用PyCharm运行**

1. 在左侧项目目录中，找到 `backend_code` -> `app.py`
2. 右键点击 `app.py`，选择 "Run 'app'"
3. 或者打开文件后，点击右上角的绿色▶️运行按钮

**方法二：使用Terminal运行**

### 1.6 访问网站

打开浏览器，在地址栏输入：`http://localhost:5000`

### 2.3 商品结算

**功能说明：**

整个结算流程分为两步：

**第一步 - 购物车页面（page_checkout.html）：**
1. 点击商品卡片上的"添加到购物车"按钮
2. 在购物车中调整商品数量
3. 选择支付方式（现金/微信/支付宝）
4. 如果需要会员折扣，输入顾客会员编号
5. 点击"确认结算"跳到会员确认页面

**第二步 - 会员确认页面（page_checkout_confirm.html）：**
1. 自动查询会员信息，显示会员等级
2. 根据等级自动计算折扣
3. 如果是生日，显示生日折扣
4. 确认后点击"确认结算"
5. 弹出结算成功提示，点击确定返回首页

**会员折扣规则：**
| 会员等级 | 折扣 | 升级所需积分 |
|---------|------|-------------|
| 普通会员 | 95折 | 0（新注册默认） |
| 银卡会员 | 92折 | 200积分 |
| 金卡会员 | 90折 | 500积分 |
| 钻石会员 | 88折 | 1000积分 |

**生日优惠：**
- 会员生日当天购物，在原有折扣基础上再打95折
- 例如：金卡会员（90折）生日当天购物 = 90折 × 95折 = 85.5折

**涉及的文件：**

### 4.3 CSV文件操作

本项目所有数据都存储在CSV文件中，使用Python内置的 `csv` 模块操作。

**读取CSV文件（DictReader方式 - 通过列名访问）：**
```python
import csv

def read_csv(filepath):
    rows = []
    if os.path.exists(filepath):
        with open(filepath, 'r', newline='', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            for row in reader:
                rows.append(dict(row))
    return rows
```

**写入CSV文件：**
```python
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['id', 'name', 'price'])  # 写表头
    writer.writerow([1, '苹果', 5.99])         # 写数据行
```

**注意事项：**
- 使用 `encoding='utf-8'` 避免中文乱码
- 使用 `newline=''` 避免写入时出现空行
- `DictReader` 返回字典格式，方便按列名访问数据

### 4.4 Flask路由基础

## ❓ 常见问题解答

### Q1：如何在PyCharm中配置虚拟环境？

**解决：**
1. 打开 "File" -> "Settings" -> "Project: chaoshiguanli" -> "Python Interpreter"
2. 点击齿轮图标，选择 "Add"
3. 选择 "Existing environment"
4. 选择虚拟环境中的 `python.exe` 路径
5. 点击 "OK"

### Q2：运行时提示找不到模块？

**解决：** 确保虚拟环境已激活，并安装了依赖包
```bash
pip install -r requirements.txt
```

### Q3：端口被占用怎么办？

**解决：** 修改 `backend_code/app.py` 文件最后一行中的端口号
```python
app.run(host='0.0.0.0', port=5001, debug=True)
```

### Q4：修改代码后没有生效？

**解决：**
1. 如果修改了Python后端代码（`.py`文件），需要重启服务器
2. 如果修改了前端页面（`.html`文件），只需刷新浏览器即可
3. 如果修改了CSV数据文件（`.csv`文件），重启服务器后生效

### Q5：如何测试会员生日折扣？

**解决：**
1. 打开 `data_files/data_members.csv`
2. 找一个会员，把它的生日改成今天的日期
3. 重启服务器
4. 用该会员编号结算，就会看到生日折扣提示

### Q6：如何查看员工履历？

**解决：**
1. 在员工管理页面，点击员工的"履历"按钮
2. 查看升职、调岗、辞职等操作记录
3. 数据存储在 `data_files/data_employee_history.csv` 中
