# 超市管理系统 - 使用教程

## 📚 教程简介

本教程将帮助你了解这个超市管理系统。通过本教程，你将学会：
- 如何运行项目（无需安装任何第三方包）
- 如何使用各个功能模块
- 关键知识点和学习训练点
- 如何修改和扩展代码

**核心特点：**

- **前端：** 纯 HTML + CSS + JavaScript（无需构建工具）

**会员折扣规则：**
| 会员等级 | 折扣 | 升级所需积分 |
|---------|------|-------------|
| 普通会员 | 95折 | 0（新注册默认） |
| 银卡会员 | 92折 | 200积分 |

- 会员生日当天购物，在原有折扣基础上再打95折

### 4.2 Python http.server 基础

本项目用 `http.server.BaseHTTPRequestHandler` 替代了 Flask，代码更简单直接。

**服务器核心结构：**
```python
import http.server
import json

class StoreHandler(http.server.BaseHTTPRequestHandler):
    
    def do_GET(self):
        # 处理 GET 请求（读取数据）
        if self.path == '/api/products':
            products = get_all_products()
            self._json_response(products)
    
    def do_POST(self):
        # 处理 POST 请求（创建数据）
        body = self._read_body()
        add_product(body['name'], body['price'])
        self._json_response({'message': '添加成功'})

# 启动服务器
server = http.server.HTTPServer(('0.0.0.0', 5000), StoreHandler)
server.serve_forever()
```

**对比 Flask：**
| | Flask | http.server |
|---|---|---|
| 依赖 | 需要 `pip install flask` | Python 自带，零依赖 |
| 路由定义 | `@app.route('/path')` 装饰器 | `if self.path == '/path'` 判断 |
| 参数获取 | `request.args.get('key')` | `urllib.parse.parse_qs()` |
| JSON 响应 | `jsonify(data)` | `json.dumps(data)` + 手动设置 headers |
| 模板渲染 | `render_template()` | 直接读取 `.html` 文件返回 |

### 4.4 CSV 文件操作

本项目所有数据都存储在 CSV 文件中，使用 Python 内置的 `csv` 模块操作。

**读取 CSV 文件（DictReader 方式 - 通过列名访问）：**
```python
import csv

def read_csv(filepath):
    rows = []
    if os.path.exists(filepath):
        with open(filepath, 'r', newline='', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            for row in reader:
                rows.append(dict(row))
    return rows
```

**写入 CSV 文件：**
```python
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['id', 'name', 'price'])  # 写表头
    writer.writerow([1, '苹果', 5.99])         # 写数据行
```

**注意事项：**
- 使用 `encoding='utf-8'` 避免中文乱码
- 使用 `newline=''` 避免写入时出现空行
- `DictReader` 返回字典格式，方便按列名访问数据

### 4.5 JSON 数据格式

前端和后端之间的数据传递使用 JSON 格式。

**JSON 格式示例：**
```json

    "price": 5.99,
```

**Python 后端接收 JSON（server.py）：**
```python
def read_body(handler):
    length = int(handler.headers.get('Content-Length', 0))
    body = handler.rfile.read(length)
    return json.loads(body.decode('utf-8'))
```

**Python 后端返回 JSON：**
```python
def json_response(handler, data):
    handler.send_response(200)
    handler.send_header('Content-Type', 'application/json; charset=utf-8')
    handler.end_headers()
    handler.wfile.write(json.dumps(data, ensure_ascii=False).encode('utf-8'))
```

**JavaScript 发送 JSON：**
```javascript
const data = { name: '苹果', price: 5.99, stock: 100 };
fetch('/api/products', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
});
```

### 4.7 纯 CSS 图表实现

**柱状图（CSS Bar Chart）：**
```javascript
function renderBarChart(containerId, labels, values, maxVal, color, prefix) {
    const container = document.getElementById(containerId);
    container.innerHTML = '<div class="bar-chart">' + labels.map((label, i) => {
        const height = maxVal > 0 ? Math.max((values[i] / maxVal) * 100, 2) : 0;
        return `
            <div class="bar-item">
                <div class="bar-value">${prefix}${values[i]}</div>
                <div class="bar-fill" style="height:${height}%; background-color:${color};"></div>
                <div class="bar-label">${label}</div>
            </div>`;
    }).join('') + '</div>';
}
```

## ❓ 常见问题解答

### Q1：如何运行项目？

**解决：** 直接运行 server.py，无需安装任何依赖
```bash
python server.py
```

### Q2：端口被占用怎么办？

**解决：** 修改 `server.py` 文件最后一行的端口号
```python
port = 5001  # 改成其他端口
```

### Q3：修改代码后没有生效？

**解决：**
1. 如果修改了 Python 后端代码（`.py`文件），需要重启服务器（Ctrl+C 然后重新运行）
2. 如果修改了前端页面（`.html`文件），只需刷新浏览器即可
3. 如果修改了 CSV 数据文件（`.csv`文件），通常刷新页面即可，个别情况需重启

### Q4：如何测试会员生日折扣？

**解决：**
1. 打开 `data/data_members.csv`
2. 找一个会员，把它的生日改成今天的日期（格式：YYYY-MM-DD）
3. 刷新页面，用该会员编号结算，就会看到生日折扣提示

### Q5：如何查看员工履历？

**解决：**
1. 在员工管理页面，点击员工的"履历"按钮
2. 查看升职、调岗、辞职等操作记录
3. 数据存储在 `data/data_employee_history.csv` 中

### Q6：如何备份数据？

**解决：**
把 `data/` 文件夹复制一份即可，所有数据都在 CSV 文件中。例如：
```bash
copy data data_backup_20260428
```

### Q7：这个项目和 Flask 版本有什么区别？

**解决：**
| | Flask 版本（旧） | http.server 版本（新） |
|---|---|---|
| 依赖 | 需要 `pip install flask matplotlib` | 零依赖，Python 标准库 |
| 启动 | `python app.py`（已废弃） | `python server.py` |
| 图表 | matplotlib 服务器端生成 PNG | CSS/JS 前端渲染 |
| 代码量 | Flask 路由 + 装饰器 | 直接的 if/else 路由判断 |
| 学习难度 | 需要理解 Flask 框架 | 只需理解基础 HTTP 和 Python |
