# 超市管理系统 - 使用教程

## 📚 教程简介

本教程将帮助你了解如何使用这个超市管理系统。本项目采用纯前端技术（HTML + CSS + JavaScript），**无需安装Python，无需运行服务器**，直接用浏览器打开就能使用！

通过本教程，你将学会：
- 如何用浏览器打开项目
- 如何使用各个功能模块
- 数据是如何存储的（localStorage）
- 关键知识点和练习建议

---

### 2.3 商品结算

**功能说明：**

整个结算流程分为两步：

**第一步 - 购物车页面（page_checkout.html）：**
1. 点击商品卡片上的"添加到购物车"按钮
2. 在购物车中调整商品数量
3. 选择支付方式（现金/微信/支付宝）
4. 如果需要会员折扣，输入顾客会员编号
5. 点击"结算"跳到会员确认页面

**第二步 - 会员确认页面（page_checkout_confirm.html）：**
1. 自动查询会员信息，显示会员等级
2. 根据等级自动计算折扣
3. 如果是生日，显示生日折扣
4. 确认后点击"确认结算"
5. 弹出结算成功提示，点击确定返回首页

**会员折扣规则：**
| 会员等级 | 折扣 | 升级所需积分 |
|---------|------|-------------|
| 普通会员 | 95折 | 0（新注册默认） |
| 银卡会员 | 92折 | 200积分 |
| 金卡会员 | 90折 | 500积分 |
| 钻石会员 | 88折 | 1000积分 |

**生日优惠：**
- 会员生日当天购物，在原有折扣基础上再打95折
- 例如：金卡会员（90折）生日当天购物 = 90折 × 95折 = 85.5折

**涉及的文件：**
- `page_checkout.html` - 购物车页面
- `page_checkout_confirm.html` - 会员确认页面（含折扣计算逻辑）
- `js/data_manager.js` - `addSale()`, `addMemberPoints()` 函数

**学习训练点：**
- 在 `page_checkout_confirm.html` 的 `showMember()` 函数中修改各等级折扣比例
- 在 `data_manager.js` 的 `addMemberPoints()` 函数中修改积分规则和升级门槛

**会员等级自动升级逻辑（在 `addMemberPoints()` 中）：**
```javascript
if (points >= 1000 && member.level !== '钻石会员') {
    member.level = '钻石会员';
} else if (points >= 500 && member.level !== '金卡会员' && member.level !== '钻石会员') {
    member.level = '金卡会员';
} else if (points >= 200 && member.level === '普通会员') {
    member.level = '银卡会员';
}
```

## 💡 第四章：重要知识点

### 4.1 HTML + CSS + JavaScript

HTML 负责页面结构，CSS 负责页面样式，JavaScript 负责页面交互和数据逻辑。

本项目所有页面都是完全独立的 HTML 文件，使用 `<script src="js/data_manager.js"></script>` 引入数据管理模块。

### 4.2 localStorage 数据存储

`localStorage` 是浏览器内置的本地存储功能，数据存储在用户浏览器中，不会丢失。

**查看方式（Chrome）：**
1. 按 F12 打开开发者工具
2. 选择"Application" → "Local Storage" → 对应网址
3. 可以看到以 `supermarket_` 开头的 key，就是系统数据

**主要数据结构：**
| localStorage Key | 对应数据 |
|-----------------|---------|
| `supermarket_products` | 商品数据 |
| `supermarket_sales` | 销售记录 |
| `supermarket_employees` | 员工数据 |
| `supermarket_employee_history` | 员工履历 |
| `supermarket_members` | 会员数据 |
| `supermarket_costs` | 成本数据 |
| `supermarket_gifts` | 礼品数据 |
| `supermarket_redemptions` | 兑换记录 |

**重置数据：** 在浏览器控制台输入 `DataManager.resetData()` 即可恢复初始数据。

### 4.3 Chart.js 图表库

Chart.js 是流行的 JavaScript 图表库，本项目使用 v4.4 版本，通过 CDN 加载。

```html
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>
```

支持的图表类型：折线图（line）、柱状图（bar）、饼图（pie）等。

### 4.4 DataManager 模块

`DataManager` 是系统的核心，采用 IIFE（立即执行函数）模式封装，避免全局变量污染。

**常用调用方式：**
```javascript
// 获取商品列表
DataManager.getProducts()

// 添加商品
DataManager.addProduct('苹果', 5.99, 100, '水果', '新鲜红苹果')

// 获取会员
DataManager.getMemberById('M001')

// 添加销售记录
DataManager.addSale('M001', 100, '现金', [
    { product_id: 1, quantity: 2 }
])
```

### 4.5 数据流向

原来的 Flask 架构中，数据流是：
- 前端 → AJAX请求 → Flask路由 → CSV文件

现在的纯前端架构中，数据流是：
- 前端JavaScript → DataManager → localStorage

简化了很多！数据就在浏览器里，读写都是瞬间完成。

## ❓ 常见问题解答

**Q1：为什么直接用浏览器打开就能用？**
A：因为项目完全用 HTML + CSS + JavaScript 写成，数据存储在浏览器的 localStorage 中，不需要任何服务器。

**Q2：数据会丢失吗？**
A：localStorage 数据会持久保存，但清除浏览器缓存会导致数据丢失。建议定期备份。

**Q3：如何重置数据？**
A：在浏览器按 F12 打开控制台，输入 `DataManager.resetData()` 回车即可恢复初始数据。

**Q4：如何查看存储的数据？**
A：按 F12 → "Application" → "Local Storage"，展开可以看到所有数据。

**Q5：不同浏览器数据互通吗？**
A：不通。localStorage 是每个浏览器独立的，Chrome 的数据在 Firefox 中看不到。

**Q6：能多人同时使用吗？**
A：因为数据在各自浏览器中，不同用户的数据是独立的。如需共享数据，需要额外的后端服务。
