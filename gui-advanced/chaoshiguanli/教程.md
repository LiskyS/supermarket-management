### 2.2 商品管理

**功能说明：**
- 查看商品列表：显示所有商品的名称、价格、库存等信息
- 添加商品：点击"添加商品"按钮，填写商品信息
- 修改商品：点击商品右侧的"编辑"按钮

### 2.3 商品结算

**功能说明：**
1. 添加商品到购物车：点击商品卡片上的"添加到购物车"按钮
2. 修改数量：在购物车中可以调整商品数量
3. 输入顾客ID：如果是会员，输入会员编号可以享受折扣
4. 选择支付方式：支持现金、微信、支付宝
5. 点击结算：跳转到会员确认页面
6. 确认结算：显示会员信息和折扣，确认后完成结算

**会员折扣规则：**
| 会员等级 | 折扣 | 升级所需积分 |
|---------|------|-------------|
| 普通会员 | 95折 | 0 |
| 银卡会员 | 92折 | 200 |
| 金卡会员 | 90折 | 500 |
| 钻石会员 | 88折 | 1000 |

**生日优惠：**
- 会员生日当天购物，在原有折扣基础上再打95折
- 例如：金卡会员生日当天购物 = 90折 × 95折 = 85.5折

**学习训练点：**
- 在 `page_checkout_confirm.html` 中修改折扣计算逻辑
- 在 `data_handler.py` 的 `add_member_points()` 函数中修改积分规则

### 2.4 数据分析

## ⚠️ 第四章：注意知识点

### 4.1 CSV文件操作

**读取CSV文件：**
```python
import csv

def read_csv(filepath):
    rows = []
    if os.path.exists(filepath):
        with open(filepath, 'r', newline='', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            for row in reader:
                rows.append(dict(row))
    return rows
```

**注意事项：**
- 使用 `utf-8` 编码避免中文乱码
- 使用 `newline=''` 避免写入时出现空行
- `DictReader` 返回的是字典，方便按列名访问

### 4.2 Flask路由基础

```python
@app.route('/api/products', methods=['GET'])
def get_products():
    products = dh.get_products()
    return jsonify(products)
```

**常用HTTP方法：**
- `GET`：获取数据
- `POST`：创建数据
- `PUT`：更新数据
- `DELETE`：删除数据

### 4.3 JSON数据格式

前端和后端通过JSON格式传递数据：

**前端发送数据：**
```javascript
const data = {
    name: '苹果',
    price: 5.99,
    stock: 100
};

fetch('/api/products', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
});
```

**后端接收数据：**
```python
data = request.get_json()
name = data['name']
price = data['price']
```

### 4.4 日期时间处理

```python
from datetime import datetime

# 获取当前时间
now = datetime.now()

# 格式化时间字符串
sale_date = now.strftime('%Y-%m-%d %H:%M:%S')
```

**日期格式说明：**
- `%Y`：4位年份
- `%m`：2位月份
- `%d`：2位日期
- `%H`：24小时制小时
- `%M`：分钟
- `%S`：秒

## ❓ 常见问题解答

### Q1：运行时提示找不到模块？

**解决：** 确保已经安装依赖包
```bash
pip install -r requirements.txt
```

### Q2：端口被占用怎么办？

**解决：** 修改 `app.py` 中的端口号
```python
app.run(host='0.0.0.0', port=5001, debug=True)  # 修改port参数
```

### Q3：数据文件在哪里？

**位置：** `data_files/` 目录下，使用CSV格式存储

### Q4：如何查看会员信息？

**方法：** 在会员管理页面查看，或直接打开 `data_files/data_members.csv`

### Q5：如何测试生日折扣？

**方法：** 修改会员数据中的生日为今天日期，然后结算时输入该会员ID
