# 超市管理系统 - 使用教程

## 一、项目简介

本项目是一个**超市管理系统**，采用纯命令行（CMD）交互方式运行。核心功能基于 Python 标准库编写。
如需图表可视化，可选安装 matplotlib，在不安装的情况下所有核心功能均不受影响。

### 适用对象
- Python 大一初学者
- 学习 CSV 文件读写、模块化编程、函数设计
- 理解真实业务场景下的数据管理逻辑

### 技术特点
| 特性 | 说明 |
|------|------|
| 编程语言 | Python 3.8+ |
| 数据存储 | CSV 文件（8张数据表） |
| 外部依赖 | 核心功能**零依赖**（仅 Python 标准库）；可视化可选安装 `matplotlib` |
| 交互方式 | 纯命令行菜单 + matplotlib 弹窗图表 |
| 代码风格 | 面向过程，函数模块化，适合初学者阅读 |

---

## 二、项目结构

```
chaoshiguanli/
├── cli.py                  # 主程序入口（命令行菜单 + 可视化入口）
├── 教程.md                  # 本教程文档
├── handler/
│   ├── data_handler.py     # 数据处理层（业务逻辑 + 分析函数）
│   └── chart_renderer.py   # 图表渲染层（matplotlib 可视化）
└── data/                   # 数据文件目录（CSV格式）
    ├── data_products.csv           # 商品数据
    ├── data_sales.csv              # 销售记录
    ├── data_employees.csv          # 员工数据
    ├── data_employee_history.csv   # 员工履历
    ├── data_members.csv            # 会员数据
    ├── data_costs.csv              # 月度成本
    ├── data_gifts.csv              # 礼品数据
    └── data_redemptions.csv        # 兑换记录
```

| 文件 | 职责 |
|------|------|
| `cli.py` | 负责所有用户交互：清屏、菜单、输入校验、CMD文字图表、可视化弹窗入口 |
| `handler/data_handler.py` | 负责所有数据处理：CSV读写、业务逻辑、增删改查、数据分析 |
| `handler/chart_renderer.py` | 负责 matplotlib 图表渲染：饼图、环形图、柱状图、折线图、混合图等 |
| `data/` 目录 | 存放所有 CSV 数据文件，首次运行自动生成 |

> **设计原则**：用户界面（cli.py）、业务逻辑（data_handler.py）和图表渲染（chart_renderer.py）完全分离。

## 三、环境要求与运行方式

### 3.1 环境要求

- Python 3.8 或更高版本
- Windows / macOS / Linux 均可
- 核心功能无需安装任何第三方包
- 可视化图表功能需要安装 `matplotlib`（可选）

### 3.2 运行方式

打开 CMD（或终端），进入项目目录，执行：

```bash
cd chaoshiguanli
python cli.py
```

首次运行后，`data/` 目录下会自动生成所有 CSV 数据文件并填入示例数据。

退出系统：在主菜单输入 `0`。

### 3.3 安装 matplotlib（可选）

如果需要 matplotlib 弹窗图表，运行：

```bash
pip install matplotlib
```

安装后，在数据分析的任意页面按 `V` 即可弹出对应的可视化图表窗口。不安装也不影响核心功能，程序会在按 `V` 时友好提示。

### 4.2 商品结算

**菜单路径**：主菜单 → `2`

结算分两步完成：

**第一步：选购商品**
- 查看商品列表，输入商品 ID 和数量加入购物车
- 支持添加多个商品、移除购物车中的商品
- 库存不足时会提示

**第二步：确认结算**
- 显示购物清单和原价合计
- 输入会员编号享受折扣（非会员直接回车跳过）

**会员折扣规则**：

| 等级 | 折扣 | 积分门槛 |
|------|------|----------|
| 普通会员 | 95折 | 0 ~ 199 |
| 银卡会员 | 92折 | 200 ~ 499 |
| 金卡会员 | 90折 | 500 ~ 999 |
| 钻石会员 | 88折 | 1000+ |
| 生日当日 | 额外再打95折 | 与等级折扣叠加 |

- 结算后自动记录销售、扣减库存、增加会员积分
- 积分达到门槛自动升级会员等级

> **支付方式**：现金、微信、支付宝

> **数据文件**：`data/data_sales.csv`

## 五、代码架构说明

### 5.1 分层设计

```
┌──────────────────────┐
│      cli.py          │  ← 用户界面层（菜单、输入、输出、CMD图表、可视化入口）
│   (主程序入口)        │
├──────────────────────┤
│ handler/data_handler  │  ← 业务逻辑层（CSV读写、增删改查、业务规则、数据分析）
│      .py              │
├──────────────────────┤
│ handler/chart_        │  ← 图表渲染层（matplotlib 饼图/环形图/柱状图/折线图/混合图）
│   renderer.py         │      懒加载设计：不安装 matplotlib 时不影响核心功能
├──────────────────────┤
│     data/*.csv        │  ← 数据持久层（8个CSV数据文件）
└──────────────────────┘
```

### 5.2 data_handler.py 核心函数

| 函数 | 功能 |
|------|------|
| `read_csv(filepath)` | 读取 CSV 文件，返回字典列表 |
| `write_csv(filepath, headers, rows)` | 覆写 CSV 文件 |
| `append_csv(filepath, row)` | 向 CSV 文件追加一行 |
| `get_next_id(filepath)` | 获取下一个自增 ID |
| `init_files()` | 首次运行时初始化所有数据文件 |
| `get_products()` | 获取所有商品 |
| `add_product(name, price, ...)` | 添加商品 |
| `update_product(pid, name, ...)` | 更新商品 |
| `delete_product(pid)` | 删除商品 |
| `search_products(keyword)` | 搜索商品 |
| `add_sale(customer_id, amount, ...)` | 记录销售（自动扣库存、加积分） |
| `get_employees()` | 获取所有员工 |
| `employee_promote(eid, ...)` | 员工升职（自动记录履历） |
| `employee_transfer(eid, ...)` | 员工调岗（自动记录履历） |
| `employee_resign(eid, ...)` | 员工辞职（自动记录履历） |
| `redeem_gift(member_id, gift_id)` | 积分兑换礼品 |

#### 数据分析函数（新增）

| 函数 | 功能 |
|------|------|
| `get_payment_method_stats()` | 支付方式统计（现金/微信/支付宝） |
| `get_daily_sales_trend()` | 每日销售趋势（金额+订单数） |

## 八、常见问题

**Q：运行报错怎么办？**

A：确保 Python 版本 ≥ 3.8，且项目目录结构完整。如遇 CSV 文件损坏，删除 `data/` 目录重新运行即可恢复初始数据。

**Q：如何清空所有数据重新开始？**

A：删除 `data/` 目录下所有 `.csv` 文件，重新运行 `python cli.py`。

**Q：能在其他电脑上运行吗？**

A：可以。将整个项目目录复制到其他电脑，只要安装了 Python 3.8+ 即可直接运行，无需任何配置。

**Q：输入错误会崩溃吗？**

A：不会。程序内置了输入校验，遇到无效输入会提示重试，不会崩溃。

**Q：按 V 提示"matplotlib 未安装"怎么办？**

A：这是因为你没有安装 matplotlib。在终端运行 `pip install matplotlib` 即可。不安装的话 CMD 文字图表一样能用，完全不影响。

**Q：matplotlib 弹窗不显示或卡住怎么办？**

A：确保安装了 matplotlib，且版本 ≥ 3.5。关闭之前打开的图表窗口后重试即可。
